# TinySky 个人主页

原生 HTML/CSS 静态主页，适用于 GitHub Pages，无需安装依赖。

本地预览：`python3 -m http.server 4387 --bind 127.0.0.1`

GitHub Pages：Settings → Pages → Deploy from a branch → main → / (root)。

## 中文字体

中文使用 Adobe 思源黑体简体中文可变字体，英文保留原有字体搭配。`tinysky-han-sans.woff2` 是按当前页面文字生成的网页子集，内部字体名为 TinySky Han Sans；新增中文文案时需要重新生成子集。原始字体：https://github.com/adobe-fonts/source-han-sans/blob/release/Variable/WOFF2/TTF/Subset/SourceHanSansCN-VF.ttf.woff2 。授权见 FONT-LICENSE.txt。
